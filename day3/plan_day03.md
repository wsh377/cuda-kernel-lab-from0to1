## 九、阶段 F：最小 CPU 算子项目（14:50-16:20）

项目：对两个等长浮点数组执行 Vector Add。

先写需求，不先搜索实现：

```text
输入：a、b 和元素数量 N
输出：output
规则：output[i] = a[i] + b[i]
范围：i 从 0 到 N-1
风险：长度不一致、空输入、下标越界
```

推荐接口：

```cpp
void vector_add(
    const std::vector<float>& a,
    const std::vector<float>& b,
    std::vector<float>& output);
```

如果 `std::vector`、引用 `&` 或 `const` 尚不能解释，可以分两步：

1. 先用三个固定长度数组完成计算。
2. 再学习完成当前接口所必需的最少 `std::vector` 知识。

不要同时学习类、模板或复杂工程结构。

## 十一、阶段 H：CUDA 条件分支（17:00-17:40）

### 路线 A：满足解锁条件

只做最小概念映射，不追求完整掌握：

```text
CPU：一个 for 循环依次处理 i=0...N-1
CUDA：许多线程各自获得一个 i，并处理一个元素
共同规则：output[i] = a[i] + b[i]
```

认识但不要求背诵：

```cpp
__global__ void vector_add_kernel(...)
```

以及典型线程索引：

```cpp
int i = blockIdx.x * blockDim.x + threadIdx.x;
```

必须先理解：这个公式的结果只是给当前线程一个一维编号；访问数组前还需要判断 `i < N`。

若本机 `nvcc` 尚未配置，本阶段只完成：

- 确认 GPU、驱动和 CUDA Toolkit 是三个不同概念。
- 记录环境现状。
- 阅读最小 Kernel 的输入、输出、索引和边界判断。
- 不在当天临时进行长时间安装。
