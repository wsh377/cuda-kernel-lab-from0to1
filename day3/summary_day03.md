## 三、数值类型

```cpp
int count = 5;
float temperature = 23.5f;
double average = 23.5;
```

- `int` 用于保存整数。
- `float` 和 `double` 用于保存带小数部分的数。
- `23.5f` 中的 `f` 表示该字面量是 `float`。
- 没有 `f` 后缀的 `23.5` 通常是 `double`。
- `double` 通常比 `float` 具有更高精度，但也通常占用更多空间。

CUDA 和机器学习程序中经常使用 `float`，因为它通常占用更少的存储空间，并且许多 GPU 对单精度运算具有较高吞吐量。但类型选择仍然要考虑精度、范围、内存和硬件性能，不能简单理解为 `float` 永远更好。

### 字面量

字面量就是直接写在代码中的具体值：

```cpp
10       // int 字面量
23.5     // double 浮点字面量
23.5f    // float 浮点字面量
'A'      // char 字面量
"Hello"  // 字符串字面量
```

变量是保存值的名称，字面量是代码中直接写出的值。`float temperature = 23.5;` 可以工作，但右侧的 `23.5` 默认是 `double`，保存时发生了向 `float` 的转换；写成 `23.5f` 可使左右类型直接一致。

## 四、`sizeof`

今天实际编写并运行了：

```cpp
std::cout << sizeof(int) << '\n';
std::cout << sizeof(float) << '\n';
std::cout << sizeof(double) << '\n';
```

`sizeof` 用来取得一个类型或对象在当前实现中占用的字节数。

注意事项：

- 当前电脑上的结果不代表所有平台永远相同。
- `sizeof` 的结果通常使用 `std::size_t` 这类无符号整数类型表示。
- 类型占用空间和能够表达的精度、范围有关，但不能仅凭字节数推断所有行为。

今天还重点区分了数组和 `vector`：

```cpp
float a[10];                 // 一个含 10 个 float 的数组
std::vector<float> b(10);    // 一个 vector，管理 10 个 float
std::vector<float> c[10];    // 一个数组，里面有 10 个 vector
```

`sizeof(a)` 计算整个固定数组本身的大小；`sizeof(b)` 只计算 `vector` 管理对象本身的大小，不包括它在另一块内存中管理的全部元素。常见 64 位实现中的 `vector` 对象可能是 24 字节，但这不是 C++ 标准规定的固定结果。

核心认识是：

```text
数组：元素就是数组对象本身的一部分。
vector：vector 对象负责管理另一块用于保存元素的内存。
```

## 五、整数除法、浮点除法与类型转换

```cpp
5 / 2       // 整数除法，得到 2
5.0 / 2.0   // 浮点除法，得到 2.5
```

运算结果首先取决于参与运算的操作数类型。

```cpp
double result = 5 / 2;
```

这段代码仍然先执行整数除法，得到整数 `2`，之后才把它转换为 `double`，因此 `result` 的值是 `2.0`，已经丢失的小数部分不会因为结果变量是 `double` 而恢复。

可以显式转换操作数：

```cpp
double result = static_cast<double>(5) / 2;
```

注意事项：

- 整数转换成浮点数通常可以保留这个简单整数的数值。
- 浮点数转换成整数会丢弃小数部分，不是四舍五入。
- 平均值计算需要防止先发生整数除法。
- 除法前还必须检查除数是否为零。

## 六、浮点数的有限精度

浮点数在计算机中通常是有限精度的二进制近似值。许多十进制小数不能被精确表示，因此某些计算结果只会非常接近期望值。

例如，复杂计算中不一定适合直接判断：

```cpp
value == 0.3
```

以后可以通过误差范围判断两个浮点结果是否足够接近。当前需要记住：浮点数适合表示小数，但通常不能把它理解成完全精确的十进制小数盒子。

## 七、函数参数的三种形式

### 7.1 按值传递

```cpp
void function(int value)
```

- 函数获得原变量的一份副本。
- 修改 `value` 只修改副本。
- 调用者的原变量不受影响。

### 7.2 引用传递

```cpp
void function(int& value)
```

- `value` 是调用者原变量的引用，不是独立副本。
- 在函数中修改 `value`，会修改调用者的原变量。

### 7.3 常量引用传递

```cpp
void function(const int& value)
```

- 引用调用者的原变量，避免复制。
- `const` 限制函数不能通过该引用修改原变量。
- 适合表达“只读取、不修改”的参数。

今天印象较深的对比是：

```text
int value        -> 复制一份，可以修改副本，不影响原变量
int& value       -> 引用原变量，可以修改原变量
const int& value -> 引用原变量，只能读取，不能修改
```

注意：引用 `&` 与指针 `*` 不是同一个概念。今天只认真学习了引用，尚未正式学习指针。

### 7.4 `void` 函数

```cpp
void print_values(...)
```

`void` 表示函数不返回一个普通值，但函数仍然可以输出内容、修改非 `const` 引用参数，或者用 `return;` 提前结束。它不能使用 `return 10;` 返回一个整数。

今天还通过参数实验进一步理解了作用域：`main` 中定义的变量名 `x` 不能直接在另一个函数中使用；调用函数后，函数内部应通过自己的参数名（例如 `value`）访问传入的数据。引用的是同一个对象，不表示两个作用域会自动共享同一个变量名。

## 八、`vector` 与 `struct`

### 8.1 `std::vector`

`vector` 解决的问题是：

> 有许多相同类型的对象，如何把它们按顺序放在一起？

例如：

```cpp
std::vector<float> values;
```

这个向量中的每个元素都是 `float`。后续需要实际学习 `size()`、`empty()`、下标访问和遍历。

今天已经理解了以下概念：

```text
values.size()  -> 元素数量，不是最大下标
values.empty() -> 判断元素数量是否为 0
values[i]      -> 按下标访问，通常不检查范围
values.at(i)   -> 按下标访问并检查范围
```

若 `size()` 为 `N`，合法下标是 `0` 到 `N-1`，因此循环条件通常写成 `i < N`。写成 `i <= N` 会访问下标 `N`。

使用 `values[i]` 越界属于未定义行为：它可能输出异常数据、破坏其他数据或导致崩溃，也可能暂时看似正常。因此“没有崩溃”不能证明没有越界。空向量的 `empty()` 为真，不能读取 `values[0]`。

### 8.2 `struct`

`struct` 解决的问题是：

> 一个对象内部有多个不同类型的数据，如何把它们组织在一起？

例如，一个学生可以同时具有字符串姓名和浮点成绩。`struct` 可以把这些相关但类型不同的数据组成一种新类型。

两者的核心区别：

```text
vector -> 多个相同类型的对象
struct -> 一个对象内部的多个不同类型字段
```

今天还理解了 `std::vector<Student>`：它表示一个向量，其中每个元素都是一个 `Student` 对象。`students[i].name` 可以拆成“先取得第 `i` 个学生，再访问这个学生的 `name` 成员”。今天主要完成概念理解，尚未独立编写完整的 `vector` 或 `struct` 程序。

## 九、CUDA Kernel 与 CPU 循环

CUDA Kernel 可以理解为：

> 由 CPU 发起，在 GPU 上由许多线程并行执行的函数。

它不是操作系统内核，也不是一个单独线程。

CPU Vector Add 通常通过循环依次处理元素：

```cpp
for (int i = 0; i < N; ++i)
{
    output[i] = a[i] + b[i];
}
```

CUDA 中则让许多线程分别获得不同的 `i`，每个线程处理一个元素。二者的计算规则仍然相同：

```cpp
output[i] = a[i] + b[i];
```

变化的是任务分配方式：CPU 循环依次处理，GPU 线程并行处理。
