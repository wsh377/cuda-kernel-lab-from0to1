# Day 4 - 回忆提纲

日期：2026-09-09

## 1. 类型、字面量与转换

- 左侧声明规定变量最终保存数据的类型；右侧表达式先产生自己的类型和值，再在需要时转换。
- `1.0` 是 `double`，`1.0f` 是 `float`；`f` 不提高精度，只是直接选择 `float`。
- 除法类型由操作数决定，结果变量不能恢复整数除法已经丢失的小数。
- `static_cast<double>(5) / 2` 执行浮点除法。

## 2. 输入与安全除法

- `std::cin` 把键盘文本按目标变量类型解析。
- `!(std::cin >> a >> b)` 表示“不能成功读取两个数”。
- `!` 对真假取反；`=` 是赋值，`==` 判断相等，`!=` 判断不等。
- 顺序：检查输入成功 -> 检查除数不为零 -> 执行除法。

## 3. 参数、`void` 与作用域

- `T value`：副本；`T& value`：可修改别名；`const T& value`：只读别名。
- `void` 不返回普通值，但可以输出、修改引用参数或使用 `return;` 提前结束。
- 函数内部只能直接使用其作用域可见的名字，通过形参接收调用者的实参。

## 4. `vector`

- `size()` 是元素数量；`empty()` 判断是否为空。
- `N` 个元素的合法下标是 `0` 到 `N-1`。
- `[]` 通常不检查边界；`at()` 检查边界。
- `push_back()` 追加元素，`resize()` 改变元素数量。
- 输出整个 `vector` 需要范围 `for` 遍历。
- `for (T value : v)` 复制；`for (T& value : v)` 可修改；`for (const T& value : v)` 只读。

## 5. CPU Vector Add

- 输入 `a`、`b` 使用 `const std::vector<float>&`。
- 输出 `output` 使用 `std::vector<float>&`。
- 先检查 `a.size() != b.size()`。
- 写 `output[i]` 前先 `output.resize(a.size())`。
- 循环条件使用 `i < a.size()`。
- `output[i] = a[i] + b[i]`。

## 6. 指针

- `&value` 取地址；`float* p` 声明指针；`*p` 解引用取值。
- `p = &x` 改变指向；`*p = value` 修改所指对象。
- `nullptr` 表示没有有效目标，不能被解引用。
- `const float* input` 不能通过指针修改数据；`float* output` 可以写数据。

## 7. 数组与指针

- 数组元素连续存放；数组名在多数表达式中转换为首元素地址。
- `p == &a[0]`。
- `a[i] == *(a + i)`，`p[i] == *(p + i)`。
- `p + 1` 是下一个同类型元素的地址；`*(p + 1)` 是该元素的值。
- 指针有效不等于任何下标都有效，仍须保证范围合法。

## 8. `vector.data()`

- `v` 是管理对象，`v.data()` 是首元素指针。
- `v.data()` 不复制数据；`data[i]` 与 `v[i]` 访问同一元素。
- 空 `vector` 的 `data()` 不能解引用。
- `push_back()` 或增大的 `resize()` 可能搬迁元素，旧指针可能失效；之后重新调用 `data()`。
